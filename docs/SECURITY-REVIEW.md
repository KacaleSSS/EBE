# v1.0.0 安全与结构修复记录

本记录描述已覆盖的边界，不构成零漏洞承诺。威胁模型为可信单用户、本机文件权限可信，网络来源与模型输出不可信。

| 发现的问题 | 修复及回归依据 |
| --- | --- |
| 下载串行、每条来源都触发镜像，失败后重复工作 | 有界线程下载、单 SQLite 写入器、批量镜像检查点、内容哈希恢复；并发与恢复测试 |
| 逐篇长上下文复核成本高，转载可能被算作多份证据 | 来源族归并、关键全检、普通分组20%确定性抽样、每主张最多3来源与有界原文窗口；精确引用校验、冲突升级、正文/策略/模型绑定缓存 |
| 稀疏核验只是旁路报告，旧 QA 可以复用 | 正式发布门槛重新检查当前来源和主张、抽中项核验状态；全文/章节/参考文献绑定，最终批准重新运行 QA |
| Python socket 保护拦不住 Windows SMB 文件路径 | 文件操作前统一拒绝 UNC、混合分隔符和设备路径；只允许受限本地只读 SQLite URI；严格部署通过 OS 无网络容器隔离 |
| 下载可能触及私网，凭据 URL 或重定向可能泄密 | 全部 DNS 结果公网校验、连接 IP 固定、每跳复验；凭据查询拒绝、fragment 清除，API 带凭据时禁重定向 |
| 截断下载仍会被记为成功，压缩响应可能膨胀 | 校验 Content-Length 与实际传输长度；压缩前后双限额、解压完整性检查、超时和失败状态 |
| 任意命令 worker 与文献解析混在联网阶段 | 禁任意命令；collector 只下载，离线 core 解析；固定 pdftotext 参数和最小环境，原生解析仍需容器限制 |
| 图片凭据容易进入项目，生成模型误当视觉审核模型 | 图片默认关闭、独立交换目录、临时交互密钥；生成和视觉模型分离；图片本地校验、去元数据、hash receipt、审核不通过不插入 |
| 图片插入相对路径不一致，PDF 缺字出现方框 | 插入路径相对指定 assets 根；外链/逃逸拒绝；PDF 字形覆盖检查及减号归一化；实际 HTML/EPUB/PDF 回归 |
| 只读状态查询却执行数据库初始化 | SQLite mode=ro + query_only；查询前后状态不变测试；loopback、Bearer、Host/Origin 保护 |
| 发布包可能带入原始书稿、运行状态和凭据 | 独立干净仓库、白名单打包、忽略运行目录与密钥、发布扫描；只使用合成测试资料 |

## 不应误解的保证

- 稀疏核验保留未检状态；来源分组是保守规则，不证明出版机构所有权或事实真伪。
- 120 篇为门槛，不以5–10GB体积替代；饱和度还需真实采集批次与主张变化记录。
- 原生扩展、映射盘、恶意管理员不受 Python hooks 完整控制。普通 pip 运行不是强沙箱；严格隐私用 OS 隔离且模型也在边界内。
- 云图片和获准的云测试是显式联网例外。不要把私密提示词发送给云提供商。
- 格式导出不是内容审核，直接 export 任意稿件不会获得发布质量背书。
- 备份与删除：同盘镜像不能抵御设备损坏，删除不等于 SSD 安全擦除；销毁数据不是自动默认动作。

验证范围与未完成外部验证见 [VALIDATION.md](VALIDATION.md)。
